# Humanitext Encyclopedia · corrections and reports

This repository receives evidence-based corrections to ancient bird and fish names, their senses, attestations, testimony, source commentary, and identification claims.

[Report a data correction](https://github.com/ikkota/humanitext-encyclopedia-reports/issues/new?template=data-correction.yml)

Include the permanent subject ID or CTS passage URN, dataset version, current reading, proposed correction, and the source evidence. Reports are reviewed separately from the saved dataset; an Issue does not automatically alter a record.

This repository contains the reporting template. The encyclopedia application, corpus, and research datasets are not hosted here.
